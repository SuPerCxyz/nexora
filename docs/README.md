# Nexora 文档索引

## 开始开发

先遵循仓库根目录 `AGENTS.md`，再从 `PROJECT_STATUS.md` 获取当前任务。

- `../SECURITY.md`：威胁模型和安全门禁。
- `testing/ACCEPTANCE.md`：功能、容量、可靠性和安全验收。

- `development/`：设计与开发过程文档。
