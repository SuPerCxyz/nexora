# 开发文档

本目录保存已确认的设计、技术 Spike 结论和长期有复用价值的开发说明。

## 规则

- 设计文件命名：`YYYY-MM-DD-<topic>-design.md`
- Spike 文件命名：`YYYY-MM-DD-<topic>-spike.md`
- 每份文档必须写目标、边界、结论、证据、风险和后续约束。
- 不保存密码、Token、私钥、完整主机地址或未脱敏日志。
- 临时聊天总结不进入本目录。
